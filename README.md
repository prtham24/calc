# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest based on the principal amount, rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest (in percentage).
- **Time:** The time period (in years).

## Features
- Accepts principal amount from the user.
- Accepts rate of interest from the user.
- Accepts time period from the user.
- Calculates and displays simple interest.

## How to Run
1. Clone this repository:
   ```bash
   git clone YOUR-REPOSITORY-URL
   ```
2. Navigate to the project directory:
   ```bash
   cd YOUR-REPOSITORY-NAME
   ```
3. Give execution permission to the script:
   ```bash
   chmod +x simple-interest.sh
   ```
4. Run the script:
   ```bash
   ./simple-interest.sh
   ```
